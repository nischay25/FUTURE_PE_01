# AI Business Copy Studio

AI Business Copy Studio is a modern AI-powered SaaS dashboard that generates professional website copy for local businesses using prompt engineering and intelligent content workflows.

## Live Demo
(https://business-copy-studio.lovable.app)

## Features

- AI-generated website copy
- Modern SaaS dashboard UI
- Dark and Light mode
- Responsive design
- Dynamic Services section
- AI hero image support
- Contact form
- Smooth scrolling animations
- Prompt template selection
- Copy and regenerate functionality
- Glassmorphism UI styling

## Technologies Used

- Lovable
- Prompt Engineering
- Modern UI/UX Design

## Prompt Templates

- Professional
- Friendly
- Luxury
- SEO Optimized
- Startup Style

## How It Works

1. User enters business details
2. AI workflow generates website copy
3. Dashboard preview updates dynamically
4. User can copy, regenerate, or download content

## Input Fields

- Business Name
- Business Type
- Services
- Target Audience
- Tone of Voice

## Generated Sections

- Homepage Hero
- About Us
- Services
- Why Choose Us
- CTA Section
- Contact Section
